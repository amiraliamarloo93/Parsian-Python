# Parsian-Python | پایتون فارسی

**Parsian-Python** پروژه‌ای آزمایشی برای تجربهٔ برنامه‌نویسی پایتون با واژه‌های فارسی است. پسوند فایل‌های برنامه .pyfa است.

> **وضعیت: پیش‌ازانتشار (0.1.0).** این پروژه هنوز زبان کامل فارسی یا جایگزین رسمی CPython نیست. نصب‌کننده پس از انتشار نخستین فایل wheel در بخش Releases قابل استفاده خواهد بود.

## نمونه

~~~python
نام = "Parsian-Python"
عدد = 10

چاپ("سلام دنیا")
چاپ(نام)
چاپ(عدد + 5)

اگر عدد > 5:
    چاپ("شرط درست است")
وگرنه:
    چاپ("شرط نادرست است")
~~~
