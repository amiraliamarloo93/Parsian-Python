**Parsian-Python** پروژه‌ای آزمایشی برای تجربهٔ برنامه‌نویسی پایتون با واژه‌های فارسی است. فایل‌های برنامه از پسوند `.pyfa` استفاده می‌کنند.

> **وضعیت: نسخهٔ آزمایشی 0.1.0 منتشر شده است؛ نسخهٔ اصلاحی 0.1.1 در حال آماده‌سازی است.** این پروژه هنوز زبان کامل فارسی یا جایگزین رسمی CPython نیست. نسخهٔ جدید تا پایان آزمون‌ها و انتشار رسمی، منتشرشده محسوب نمی‌شود.

## نمونه

```python
نام = "Parsian-Python"
عدد = 10

چاپ("سلام دنیا")
چاپ(نام)
چاپ(عدد + 5)

اگر عدد > 5:
    چاپ("شرط درست است")
وگرنه:
    چاپ("شرط نادرست است")
```

## افزونهٔ Visual Studio Code

کد اولیهٔ افزونه در پوشهٔ [vscode-extension](vscode-extension/) قرار دارد. این نسخه فایل‌های `.pyfa` را شناسایی می‌کند، رنگ‌آمیزی پایه دارد و فرمان اجرای فایل فعال را به مترجم نصب‌شده متصل می‌کند. بستهٔ VSIX هنوز به‌عنوان نسخهٔ رسمی منتشر نشده است.
