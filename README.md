# Parsian-Python | پایتون فارسی

**Parsian-Python** پروژه‌ای برای تجربه برنامه‌نویسی پایتون با واژه‌ها و مستندات فارسی است. پسوند فایل‌های زبان در این پروژه `.pyfa` است.

> وضعیت: نمونه اولیه و در حال توسعه — نسخهٔ 0.1.0 هنوز زبان کامل یا جایگزین رسمی CPython نیست.

## شروع سریع

برای اجرای نمونهٔ اولیه، Python 3.10 یا جدیدتر نصب کنید. سپس مخزن هسته را دریافت و طبق README آن راه‌اندازی کنید. نمونه‌ای از کد:

```python
نام = "Parsian-Python"
عدد = 10

چاپ("سلام دنیا")
چاپ(نام)
چاپ(عدد + 5)

اگر عدد > 5:
    چاپ("شرط درست است")
وگرنه:
    چاپ("شرط نادرست است")
```
